# ASR

Repo: https://github.com/phamtrongthang123/wslASR

Quick overview (from repo README):
- Local-first browser UI + Python backend for speech-to-text using NVIDIA Parakeet (nvidia/parakeet-tdt-0.6b-v2).
- Features: drag-and-drop audio, mic recording, timestamps, multiple export formats, GPU support with CUDA-enabled PyTorch.
- Runs a local server (default 0.0.0.0:3002) and stores jobs under ./data.

Notes:
- Whisper runner instructions are in `whisper/`.
